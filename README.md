# REFramework (nightly) on openmods

This repository only lists [praydog's REFramework](https://github.com/praydog/REFramework) on
[openmods](https://openmods.nexus/mods/kintaromodding/reframework-upstream). It holds no REFramework code and no
REFramework files.

- `openmods.json`: the listing data (games, tags, links, the upstream repositories)
- `openmods.md`: the text of the listing page

Downloads: the [REFramework nightly releases](https://github.com/praydog/REFramework-nightly/releases). Bugs in
REFramework go to the [REFramework issues](https://github.com/praydog/REFramework/issues).
